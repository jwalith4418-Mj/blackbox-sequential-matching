THE DAILY DECISION LOOP

Clarify → allocate → observe

  1. Read disclosed profiles and already observed feedback.
  2. Ask permitted hard-constraint questions within 12 units; a bundle costs 3.
  3. Recheck reciprocal eligibility and select non-overlapping, non-repeated pairs by observed soft agreement.
  4. Advance the synthetic world, save its new revision and return only current observations.

Days 0–59 allow introductions. Days 60–99 collect follow-up. At day 100, Results shows the completed session.

MLOPS & RELEASE DISCIPLINE

Research earns promotion.

The offline Python research package trains and evaluates candidates on declared synthetic worlds, retains source and plan digests, and reports primary timely success separately from eventual interest.

Recorded comparisons have not established a candidate advantage sufficient for promotion. The live application uses the conservative JavaScript policy port. The learned models do not drive this deployment.

Its JavaScript simulator has a separate random generator; live scores are not official Python benchmark evidence. Windows and constrained Docker certification of the research package remain open.
